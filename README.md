# CYBERLAB

My Mobile Cybersecurity Learning Lab.

## About
This project is developed using Nokia G42
and Termux.

## Projects

### 1. Network Information Tool
- Device information
- Local IP detection
- DNS lookup

### 2. Website Header Checker
- HTTP status
- Security headers inspection

### 3. Port Checker
- TCP port connectivity testing
- Open and closed port reporting

## Technologies
- Python
- Termux
- Git
- Linux

## Purpose
Learning Python, Networking,
Ethical Hacking and Cybersecurity.

## Disclaimer
Use these tools only on devices
and systems you own or have permission
to test.
